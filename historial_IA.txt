Paso 8. Crear el archivo main.py
Para demostrar que el proyecto funciona, puedes utilizar este código sencillo:


def saludar(nombre):
    """Devuelve un saludo para el usuario."""
    return f"Hola, {nombre}. ¡Bienvenido a Python!"


def main():
    nombre = input("Escribe tu nombre: ").strip()

    if nombre:
        print(saludar(nombre))
    else:
        print("Debes escribir un nombre.")


if __name__ == "__main__":
    main()
