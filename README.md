# Proyecto Python en PyCharm

## 1. Objetivo

Configurar un entorno de desarrollo en PyCharm Community, crear un proyecto en Python y utilizar herramientas de inteligencia artificial y análisis de código para mejorar la calidad del programa.

## 2. Herramientas utilizadas

- Entorno virtual `.venv` es una carpeta especial dentro de mi proyecto de Python que me permite instalar y organizar las librerías que necesite para el proyecto sin mezclarlas con mis otros proyectos.

- ChatGPT como asistente de inteligencia artificial.

- Rainbow Brakets es para que el código sea más fácil de leer, porque colorea los paréntesis, corchetes y llaves con diferentes colores.

## 3. Pasos realizados

1. Creé el proyecto `PythonProject` en PyCharm.
2. Configuré el entorno virtual de Python.
3. Creé el archivo `main.py`.
4. Escribí un programa que solicita el nombre del usuario y muestra un saludo.
5. Ejecuté el programa y comprobé que terminó correctamente.
6. Creé los archivos `requirements.txt` y `README.md`.
7. Verifiqué que el complemento SonarQube for IDE estuviera habilitado.
